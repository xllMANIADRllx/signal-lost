SIGNAL LOST — MAC INSTALLATION GUIDE
=====================================

If you see "Signal Lost is damaged and can't be opened" follow these steps:

OPTION 1 — Easy way (Right-click method)
-----------------------------------------
1. Drag Signal Lost to your Applications folder
2. Right-click on Signal Lost in Applications
3. Click "Open"
4. Click "Open" again in the popup
5. Game will launch normally from now on

OPTION 2 — Terminal method
----------------------------
1. Drag Signal Lost to your Applications folder
2. Open Terminal (press Cmd+Space, type "Terminal", hit Enter)
3. Copy and paste this command:

   xattr -cr "/Applications/Signal Lost.app"

4. Press Enter
5. Launch Signal Lost normally

This is a one-time step. The game will open normally every time after that.

This message appears because Signal Lost is an indie game not signed
with an Apple Developer certificate. It is completely safe to run.

Enjoy the game!
